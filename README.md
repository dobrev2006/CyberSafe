# CyberSafe — сайт за киберсигурност (нов дизайн)

Светъл „редакционен“ дизайн: хартиен фон, графит, лаймов акцент и серифни заглавия.
В началото има 3D катинар с комбинация. Можеш да въртиш диска с мишката, а при скрол
катинарът набира комбинацията 3-7-1-9-4 (по една цифра за всеки от 5-те навика) и се заключва.

## Файлове
- `index.html` — структурата и текстовете на страницата
- `style.css`  — целият дизайн (цветовете са най-горе: `--paper`, `--ink`, `--lime`, `--alert`)
- `main.js`    — 3D катинарът, анимациите и цялата интерактивност
- `data.js`    — съдържанието: въпросите за теста, измамите, речника и инцидентите
- `img/`       — трите картинки към заплахите

## Как да го пуснеш във Visual Studio Code
1. Разархивирай `cybersafe-new-design.zip` (десен бутон → Extract All).
2. Отвори VS Code → File → Open Folder… → избери папката `cybersafe`.
3. Натисни Ctrl+Shift+X, потърси **Live Server** (от Ritwick Dey) и натисни Install.
4. Десен бутон върху `index.html` → **Open with Live Server**.
5. Сайтът се отваря на адрес като `http://127.0.0.1:5500`. При всяко запазване (Ctrl+S) се обновява сам.

Важно: не отваряй `index.html` с двоен клик. Кодът използва JavaScript модули
(`import`), които браузърът блокира при директно отваряне на файла.
Нужен е интернет — Three.js, GSAP, Lenis и шрифтовете се зареждат от CDN.

## Какво е интерактивно
- 3D катинар: върти диска с мишката/пръста; при скрол набира комбинацията и се заключва
- Проверка на парола + бутон „Предложи силна парола“
- Тест с 3 нива (Лесно / Средно / Трудно), разбъркани въпроси и личен рекорд
- 7 вида измами — отварят се в страничен панел
- Симулатор на фишинг — кликаш подозрителните части на имейла
- Речник с търсене и филтър по буква
- Център за реакция — търсене + чеклисти, които се запазват в браузъра
